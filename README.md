# رُوح | Rou7-perfume

متجر إلكتروني فاخر مستوحى من الهوية البصرية لعلامة **رُوح | Rou7 Perfume**.

## الميزات الرئيسية
- **دعم ثنائي اللغة كامل (عربي / إنجليزي):** مع دعم كامل للاتجاهين RTL و LTR.
- **تكامل مباشر مع Supabase:** إدارة العطور وتتبع الطلبات وتحديث فوري (Realtime).
- **لوحة إدارة متطورة (`admin.html`):**
  - إضافة وتعديل وحذف المنتجات مع رفع الصور مباشرة إلى Supabase Storage (`products` bucket).
  - إدارة الطلبات، وتغيير حالات الطلبات فوريًا.
  - فتح محادثة WhatsApp مباشرة مع العميل بنقرة واحدة مع رسالة مجهزة ومخصصة لكل طلب.
  - فاتورة قابلة للطباعة وعرض تفاصيل الطلب بالكامل.
- **طلب مباشر عبر WhatsApp:** إرسال تفاصيل الفاتورة والعطور والبيانات مباشرة إلى واتساب المتجر.
- **روابط التواصل الاجتماعي الرسمية:** فيسبوك، إنستغرام، وواتساب.
- **مظهر داكن وفاتح (Dark / Light mode):** متناسق مع ألوان الهوية: الكحلي الفاخر، العاجي، والوردي.
